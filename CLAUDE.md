# Ernie Reports

The public-facing frontend for the **Let's Play Two!** fantasy baseball league. Built on data from **Ernie Remembers** (`~/Projects/ernie-remembers/`), which handles all Yahoo API fetching, analytics, and SQLite storage.

## Relationship to Ernie Remembers

- **Ernie Remembers** = data engine (Python, SQLite, Yahoo API, analytics)
- **Ernie Reports** = presentation layer (static site, HTML/CSS/JS)
- Data flows one way: Remembers exports JSON snapshots -> Reports reads them
- Reports never touches the SQLite database directly

## Design Direction: "The Press Box"

The aesthetic is inspired by the Wrigley Field hand-operated scoreboard — deep green steel panels, hand-hung number plates, decades of Chicago weather and stadium lights. The design should feel like walking into a legendary press box where a beat writer has covered this league since 2004.

### The Wrigley Green

The real Wrigley Field scoreboard paint is Benjamin Moore SC-62 "Wrigley Field Green" (`#4b5a51` — a muted grey-green). For screen use, we boost saturation slightly to capture the *under-the-lights* feeling while keeping the authentic warmth:

- **Board background**: `#3B5346` (the core Wrigley green, screen-optimized)
- **Board dark**: `#2A3D32` (deep shadow)
- **Board text**: `#D4E4C8` (aged white number plates)
- **Board bright**: `#E8F0D8` (freshly hung numbers, slight glow)
- **Board dim**: `#6B8B73` (faded/inactive numbers)

### Full Palette

- Ink (text): `#1a1612` (warm near-black)
- Parchment (backgrounds): `#f4efe6` (aged paper)
- Amber (accent/brand): `#c4841d` (stadium lights, brass fixtures)
- Grass (positive): `#2d6b3f` (outfield grass, wins)
- Clay (negative): `#b85c38` (warning track, losses)
- Chalk (white): `#fefcf6` (baseline chalk)

### Typography

- **Display**: Playfair Display (headlines, names, editorial)
- **Stats**: Oswald (numbers, rankings, scoreboard)
- **Body**: Source Serif 4 (readable prose, newsletter text)
- **Mono**: JetBrains Mono (metadata, labels, records)

## Data files (generated — never hand-edit)

`python -m src.cli export` in ernie-remembers writes:

- `src/data/data.js` — `window.ERNIE_DATA`, everything except newsletter bodies
  (summary, standings, Elo, managers, matchups, draft, transactions, history,
  weekly_standings, rivalries, records, newsletter index)
- `src/data/newsletters.js` — `window.ERNIE_NEWSLETTERS`, full newsletter
  content, lazy-loaded on first visit to the archive
- `src/data/keepers.js` — `window.ERNIE_KEEPERS`, from
  ernie-remembers/scripts/export_keepers.py (which reads the Sandcastle
  keeper workbook; MLB teams resolve live via crosswalk + warehouse rosters)

## Architecture (2026-08 rebuild)

- **Three-section nav**: This Season (Standings / This Week / Keepers /
  Playoff Odds / The Wire), The Archive (Newsletters / Season Replay /
  Draft Room / Records & Champions / History), Managers (Careers & Rivalries).
  Router in app.js (`getSections()`, hash-based); subnav row under the masthead.
- **Managers page**: career cards (tenure, title stars, finish strips) + the
  12×12 lifetime Rivalry Grid + Alumni. NO composite grading of managers —
  that was deliberately removed (see docs/site-review-2026-08-18.md); do not
  reintroduce rankings of people without a decision from Ryan.
- **Records & Champions** replaced the old Power Rankings tab. Champions list
  suppresses the in-progress season (final_rank is provisional mid-year).
- **Elo everywhere is the 2022+/K=20 canon** — matches the newsletters; never
  publish the old 2009-start numbers.
- **Playoff Odds page**: iframes `playoff-odds.html` (self-contained chart,
  pinned light via `data-theme="light"`), regenerated by ernie-remembers
  scripts/playoff_odds_history.py (50k sims, parallelized) +
  render_odds_chart.py.
- **Newsletter reader** converts markdown in-browser (tables, headers,
  comment-stripping in app.js). Corrections policy: corrections are appended
  to the archive (2026-corrections.md), never rewritten into past editions.
- **Manager identities are post-census** (2026-08-18): Alex K ≠ Alex T,
  Casey '18 / David '18, "Former manager" for de-identified/unknown people.
  First-names-only for former members — never add last names.

## Cache busting (required on every deploy)

Browsers cache app.js/data.js hard; stale script + new HTML = dead nav.
Every asset reference carries `?v=YYYYMMDDHHMM`. Before each push:

```bash
V=$(date +%Y%m%d%H%M) && sed -i '' -E "s/\?v=[0-9]{12}/?v=$V/g" index.html
```

The lazy newsletter loader self-versions off `ERNIE_DATA.exported_at`.
